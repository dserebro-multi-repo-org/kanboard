Keyboard shortcuts

Board/Calendar/List view

  • Switch to the project overview = v o
  • Switch to the board view = v b
  • Switch to the list view = v l

Board view

  • New task = n
  • Expand/collapse tasks = s
  • Compact/wide view = c

Task view

  • Edit task = e
  • New subtask = s
  • New comment = c
  • New internal link = l

Application

  • Display list of keyboard shortcuts = ?
  • Open board switcher = b
  • Go to the search/filter box = f
  • Reset the search/filter box = r
  • Close dialog box = ESC
  • Submit a form = CTRL+ENTER or ⌘+ENTER
