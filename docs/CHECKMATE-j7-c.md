# Kanboard Test Directories

The `tests/` directory contains the following subdirectories:

- `units/` - unit tests for models, core services, helpers, and more.
- `integration/` - JSON-RPC API integration tests, run against a live instance.
- `configtest/` - tests that validate the default configuration file.
- `configs/` - per-database (MySQL, PostgreSQL, SQLite) config files for the test runs.
